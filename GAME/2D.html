2D Games 🎮🕹️

Foundation of Game Development

1. What are 2D Games?

2D games are games where movement happens in two dimensions: X (left-right) and Y (up-down).

2. Popular 2D Games

Mario 🍄
Flappy Bird 🐦
Doodle Jump 🟡
Temple Run (2D versions) 🏃
Stardew Valley 🌾

3. Core Concept

X-axis → left & right
Y-axis → up & down
No depth (Z-axis not used)

4. Game Loop

Input → Update → Render → Repeat 🔁

5. Player Movement

Left Arrow ← move left
Right Arrow → move right
Space → jump

6. 2D Physics

Gravity 🌍 → pulls player down
Collision 💥 → detects touching objects
Velocity 🚀 → movement speed

7. Engines for 2D Games

Unity 🎮 → best for 2D + C#
Unreal 🎮 → advanced 2D/3D
Godot ⚡ → lightweight 2D engine

8. Game Structure

Player 👤
Enemies 👾
Obstacles 🧱
Score System 🏆
Levels 🎯
