Game Physics 🎮⚙️

How Games Simulate Real World Motion

1. What is Game Physics?

Game physics is the system that simulates real-world laws like gravity, motion, collisions, and forces inside a game engine.

2. Core Concepts

Gravity 🌍 → pulls objects down
Force 💪 → pushes objects
Velocity 🚀 → speed + direction
Acceleration ⚡ → change in velocity

3. Collision System

Box Collider 📦 → simple shape collision
Sphere Collider ⚪ → round objects
Mesh Collider 🧩 → complex shapes

4. Rigidbody (Core Physics Object)

Adds physics behavior to objects:
- Gravity
- Mass
- Forces
- Real movement

5. Basic Physics Formula

F = m × a
Force = mass × acceleration

6. Real Game Physics Examples

Jumping → gravity + velocity
Shooting → projectile motion
Driving → friction + acceleration
Falling objects → gravity simulation

7. Types of Physics

Rigid Body Physics 🧱 → solid objects
Soft Body Physics 🧸 → cloth, jelly
Fluid Physics 🌊 → water, smoke

8. Physics in Game Engines

Unity → PhysX engine ⚙️
Unreal → Chaos Physics Engine ⚡
Both handle:
- Collisions
- Gravity
- Simulation
