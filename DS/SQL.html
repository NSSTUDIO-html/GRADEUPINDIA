Database Management & Queries

1. What is SQL?

SQL (Structured Query Language) is used to store, retrieve, and manage data in databases.

2. Create Table

CREATE TABLE students (
  id INT,
  name VARCHAR(50),
  marks INT
);

3. Insert Data

INSERT INTO students VALUES (1, 'John', 80);

4. Select Data

SELECT * FROM students;

5. WHERE Clause

SELECT * FROM students WHERE marks > 50;

6. Update Data

UPDATE students SET marks = 90 WHERE id = 1;

7. Delete Data

DELETE FROM students WHERE id = 1;

8. Joins

SELECT * FROM A
JOIN B ON A.id = B.id;

9. Aggregate Functions

SELECT AVG(marks), MAX(marks) FROM students;
