Understand Data & Extract Insights

1. What is Data Analysis?

Data Analysis is the process of inspecting, cleaning, transforming, and interpreting data to find useful insights.

2. Steps

1. Collect data
2. Clean data
3. Explore data
4. Visualize data
5. Interpret results

3. Load Data

import pandas as pd

df = pd.read_csv("data.csv")
print(df.head())

4. Explore Data

print(df.info())
print(df.describe())

5. Filtering

df[df["Age"] > 25]

6. Grouping

df.groupby("Gender")["Salary"].mean()

7. Visualization

import seaborn as sns
sns.histplot(df["Age"])

8. Correlation

df.corr()

9. Save Results

df.to_csv("output.csv")
