Pandas Complete Guide 📊🐼

Data Analysis Library for Python

1. What is Pandas?

Pandas is a Python library used for data analysis, manipulation, and working with structured data like tables (Excel-like data).

2. Installation

pip install pandas

3. Import Pandas

import pandas as pd

4. Series (1D Data)

data = [10, 20, 30]

s = pd.Series(data)
print(s)

5. DataFrame (2D Table)

data = {
  "Name": ["A", "B", "C"],
  "Age": [20, 21, 22]
}

df = pd.DataFrame(data)
print(df)

6. Read CSV File

df = pd.read_csv("data.csv")
print(df.head())

7. Basic Operations

df.head()     # first 5 rows
df.tail()     # last 5 rows
df.info()     # summary
df.describe() # statistics

8. Filtering Data

df[df["Age"] > 20]

9. Missing Data

df.isnull()
df.dropna()
df.fillna(0)
