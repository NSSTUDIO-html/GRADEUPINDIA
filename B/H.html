Hardhat 🛠️⛓️

Ethereum Development Framework

1. What is Hardhat?

Hardhat is a development environment used to compile, test, debug, and deploy Ethereum smart contracts.

2. Why Hardhat?

Build smart contracts faster ⚡
Test contracts locally 🧪
Deploy to testnets/mainnet 🌐
Debug transactions 🔍

3. Key Features

Local blockchain network 🖥️
Built-in testing framework 🧪
Console debugging 🔍
Plugin system ⚙️

4. Installation

npm install --save-dev hardhat

npx hardhat

5. Hardhat Workflow

Write Contract → Compile → Test → Deploy → Verify

6. Local Blockchain

Hardhat Network = Fake Ethereum blockchain
Used for testing without real money 💰❌
