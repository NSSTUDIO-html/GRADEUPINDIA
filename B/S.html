Solidity Guide 🧑‍💻⛓️

Smart Contract Programming Language

1. What is Solidity?

Solidity is a high-level programming language used to write smart contracts on Ethereum blockchain.

2. Key Features

Contract-based language
Statically typed
Runs on Ethereum Virtual Machine (EVM)

3. Basic Structure

pragma solidity ^0.8.0;

contract MyContract {
    uint value;
}

4. Data Types

uint → positive numbers
int → integers
bool → true/false
string → text
address → wallet address

5. Functions

function setValue(uint _value) public {
    value = _value;
}

6. Simple Smart Contract Example

pragma solidity ^0.8.0;

contract Storage {
    uint data;

    function set(uint _data) public {
        data = _data;
    }

    function get() public view returns (uint) {
        return data;
    }
}

7. Important Keywords

public → accessible
private → restricted
view → read-only
pure → no state change

8. Use Cases

  • DeFi apps 💰
  • NFT platforms 🖼️
  • Voting systems 🗳️
  • Decentralized apps (DApps) 🌐
