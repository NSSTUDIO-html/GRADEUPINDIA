SQLite Complete Guide 🗄️

Lightweight Database for Apps

1. What is SQLite?

SQLite is a lightweight, serverless database used in Android, iOS, and small applications.

2. Features

- No server needed
- Fast and lightweight
- Stored in a single file
- Used in mobile apps

3. Create Table

CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT,
  age INTEGER
);

4. Insert Data

INSERT INTO users (name, age)
VALUES ('Sasank', 18);

5. Read Data

SELECT * FROM users;

6. Update Data

UPDATE users
SET age = 20
WHERE name = 'Sasank';

7. Delete Data

DELETE FROM users
WHERE id = 1;
